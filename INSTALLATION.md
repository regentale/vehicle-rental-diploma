# Пошаговая инструкция по установке (INSTALLATION)

## 0. Системные требования
Вам понадобятся установленные на вашем компьютере:
- **Node.js** (версия 18 или выше). [Скачать Node.js](https://nodejs.org/)
- Инструмент управления пакетами: **npm** (идет вместе с Node.js) или **yarn**.
- Git (опционально, для скачивания).

**Важное замечание:** Устанавливать PostgreSQL или любую другую базу данных **НЕ требуется**. Вся информация сохраняется в JSON-файлах в папке `backend/data/`.

---

## 1. Подготовка файлов проекта

Скачайте репозиторий с проектом в удобную для вас папку или клонируйте с помощью Git:
```bash
git clone <URL_репозитория>
cd "путь/к/папке/с/проектом"
```

---

## 2. Установка зависимостей

В корневой папке проекта (там же, где находится файл `package.json`) откройте терминал или командную строку и выполните:
```bash
npm run install:all
```
Этот скрипт автоматически установит зависимости как для **backend**, так и для **frontend**.

---

## 3. Требуемые переменные окружения

Чтобы система заработала, нужно настроить параметры `backend`.
Вам потребуется создать файл `.env` внутри папки `backend` (`backend/.env`). 
Вы можете скопировать `backend/.env.example` или создать новый:

```env
PORT=5005
NODE_ENV=development

# JWT секрет (используется для шифрования)
JWT_SECRET=super_secret_jwt_key
JWT_EXPIRES_IN=7d

# Адрес фронтенд-сервера для CORS
FRONTEND_URL=http://localhost:5173

# Ключи Stripe (если хотите тестировать оплату, иначе можно закомментировать)
STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...
```

*Frontend* уже настроен на обращение к серверу через собственный конфигурационный файл Vite (proxy: localhost:5005), так что добавление переменных `.env` в frontend опционально.

---

## 4. Запуск проекта

У нас настроен удобный запуск обоих частей проекта (frontend и backend) одной командой!

Вам просто нужно находиться в корне проекта и написать:
```bash
npm run dev
```

- Backend моментально запустится на порту **5005**. (Автоматически создадутся пустые таблицы/файлы базы данных в папке `backend/data`, если их еще нет)
- Frontend (Vite) запустится на порту **5173**. 
- Приложение автоматически откроется в вашем браузере по адресу `http://localhost:5173`

---

## Возможные проблемы
* Если скрипт `npm run dev` выдает ошибку: Откройте **два раздельных терминала**. 
  * В первом перейдите в backend: `cd backend` -> `npm run dev`
  * Во втором перейдите в frontend: `cd frontend` -> `npm run dev`
* Если вы получаете ошибки при загрузке картинок - создайте пустую папку `uploads` в директории `backend`.
